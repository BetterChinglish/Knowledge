# 安装

```
npm i rollup @babel/core @babel/preset-env rollup-plugin-babel rollup-plugin-serve cross-env -D

// rollup
// 打包工具

// @babel/core
// 用babel的核心模块

// @babel/preset-env
// babel的预设环境，将高级语法转换为低级语法

// rollup-plugin-babel
// rollup的babel插件

// rollup-plugin-server
// rollup的服务插件

// cross-env
// 跨平台设置环境变量
```
